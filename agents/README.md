# Agent Registry

هر Agent مالک یک واحد مشخص است.
ابتدا بررسی و گزارش؛ تغییر کد فقط با مجوز مرحله مربوطه.

## Agents

1. CORE
   Owner: contracts/core
   مسئول: قراردادهای مشترک، مدل‌های پایه، شناسه‌ها، وضعیت‌ها،
   خطاها، تنظیمات و استانداردهای مشترک.

2. DATA MANAGER
   Owner: units/data-manager, contracts/data
   مسئول: مدل‌ها و Schema، چرخه تغییرات پایگاه داده،
   اعتبارسنجی، مجوزها و Data API.

3. CODE MANAGER
   Owner: units/code-manager, contracts/code
   مسئول: مدیریت کد و اسکریپت‌ها، نسخه‌بندی، ثبت و بازیابی
   ارجاع‌های کد؛ بدون مالکیت زمان‌بندی اجرا.

4. WORKER MANAGER
   Owner: units/worker-manager
   مسئول: ثبت و پیکربندی Workerها، مدیریت چرخه اجرا،
   درخواست اجرا و زمان‌بندی.

5. WORKER RUNTIME
   Owner: units/worker-runtime, contracts/worker
   مسئول: قرارداد اجرای مشترک Worker، ورودی و خروجی،
   وضعیت، خطا، اجرای مستقل یا فراخوانی Workerهای دیگر،
   پردازش و تجمیع نتایج.

6. DASHBOARD CORE CONSUMER
   Owner: units/consumers/dashboard-core, contracts/consumer
   مسئول: هسته داشبورد، رجیستری ماژول‌ها، قالب‌ها و اتصال
   داشبورد به APIهای عمومی؛ بدون دسترسی مستقیم به پایگاه داده.

## Shared Rules

- مالکیت هر Agent محدود به واحد تعیین‌شده است.
- ابتدا کد و مستندات موجود را بررسی کن؛ قابلیت آماده را بازنویسی نکن.
- به مخازن دیگر فقط برای بررسی وابستگی‌ها مراجعه کن.
- تغییر کد متعلق به Agent دیگر ممنوع است؛ وابستگی را گزارش کن.
- دسترسی مستقیم مصرف‌کنندگان به پایگاه داده ممنوع است.
- ابتدا قرارداد و وابستگی‌ها مشخص شوند؛ سپس پیاده‌سازی.
- هیچ انتقال، حذف یا بازنویسی کدی بدون مجوز مرحله مربوطه انجام نشود.
- اسرار، کلیدهای خصوصی و فایل‌های .env را گزارش یا منتشر نکن.
- گزارش‌ها و توضیحات به زبان فارسی باشند.
- نخستین پاسخ: مراحل کار را فهرست کن.
- هر گزارش بعدی: مرحله فعلی، نتیجه و مرحله بعد را مشخص کن.

# ایجنت‌های تخصصی

هر ایجنت مسئول یک واحد مشخص است.

قوانین:
- ابتدا مراحل کار را فهرست کند.
- قبل از تغییر، وضعیت موجود را بررسی کند.
- فقط محدوده مسئولیت خودش را تغییر دهد.
- قراردادهای موجود را بی‌دلیل بازنویسی نکند.
- گزارش مراحل و تست‌ها را به فارسی ارائه کند.
- فرمان‌های ترمینال پروژه را با clear آغاز کند.

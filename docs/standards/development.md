# استاندارد توسعه

- پیش از تغییر، ساختار موجود را بررسی کن.
- از ایجاد قابلیت تکراری خودداری کن.
- تغییرات را به محدوده واحد مسئول محدود کن.
- تست‌های مرتبط را اجرا کن.
- توضیحات و گزارش‌ها باید فارسی باشند.
- فرمان‌های ترمینال پروژه باید با clear شروع شوند.
- تغییرات مخازن موجود تا پیش از مرحله انتقال ممنوع است.

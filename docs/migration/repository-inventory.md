# فهرست مخازن موجود

> این سند baseline/تاریخچه است؛ برای وضعیت نسخه فعلی به [دفترچه جامع](../manual/18-extension-and-governance.md) مراجعه کنید. نتیجه یا محدودیت قدیمی را بدون بررسی SHA به نسخه فعلی نسبت ندهید.


وضعیت: در انتظار بررسی.

برای هر مخزن ثبت شود:
- آدرس مخزن
- مسئولیت فعلی
- زبان و ابزارهای ساخت
- ساختار فایل‌ها
- قراردادها و APIها
- تست‌ها
- وابستگی‌ها
- مقصد پیشنهادی در Monorepo
- وضعیت انتقال

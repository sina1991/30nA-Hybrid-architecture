# فصل U-01 — DATA MANAGER

## مسیرها و مسئولیت

- پیاده‌سازی: `units/data-manager/`
- قراردادها: `contracts/data/`
- آزمون‌ها: `units/data-manager/tests/`
- اجرای مستندشده: `python3 units/data-manager/run.py`
- آزمون مستندشده: `python3 -m unittest discover -s units/data-manager/tests -v`
- پورت محلی پیش‌فرض در README یونیت: 8080

DATA MANAGER مالک مدل‌های داده، اعتبارسنجی، ذخیره‌سازی، migration، کنترل مالکیت و Data API است. مصرف‌کنندگان نباید مستقیماً به پایگاه داده دسترسی داشته باشند.

## فناوری و پیکربندی ثبت‌شده

- ذخیره‌سازی فعلی: SQLite.
- تنظیمات مستندشده: `DATA_MANAGER_DB`, `DATA_MANAGER_HOST`, `DATA_MANAGER_PORT`.
- هویت از `REMOTE_USER` خوانده می‌شود و فقط در صورت تنظیم توسط لایه احراز هویت مورد اعتماد معتبر است.
- `DATA_MANAGER_ALLOW_INSECURE_HEADER=1` فقط برای آزمایش محلی است و نباید در محیط عملیاتی فعال شود.

## محدودیت‌های ثبت‌شده در README یونیت

- سامانه کامل نقش‌ها و مجوزهای قابل پیکربندی وجود ندارد.
- مدیریت/اجرای Migration توسط مدیر ارائه نشده است.
- قراردادهای `contracts/data/` هنوز پیش‌نویس‌اند و باید با CORE تطبیق داده شوند.

## موارد ممیزی

- تراکنش‌ها، migration ordering و سازگاری نسخه Schema؛
- مجوزهای مالکیت در همه endpointها و جلوگیری از IDOR؛
- اعتبارسنجی ورودی، اندازه درخواست و خطاهای پایگاه داده؛
- رفتار در برابر قطع فرایند و backup/restore؛
- قراردادهای API و سازگاری Consumerها؛
- تست‌های منفی و migration از نسخه‌های واقعی داده.

## معیار تکمیل

قرارداد DATA نهایی و آزموده باشد؛ همه عملیات مالکیت‌محور تست منفی داشته باشند؛ migration و بازیابی مستند باشند؛ هیچ مصرف‌کننده‌ای به storage داخلی وابسته نباشد.

## وضعیت

بررسی اولیه بر اساس README و موجودی مخزن؛ کد و همه تست‌ها هنوز ممیزی کامل نشده‌اند.

# وابستگی‌های معماری

- واحدها باید از قراردادهای عمومی استفاده کنند.
- مصرف‌کنندگان نباید به ساختار داخلی دیتابیس وابسته باشند.
- Workerها باید قرارداد اجرایی مشترک داشته باشند.
- Orchestrator Worker نوعی Worker است، نه سیستم مستقلی
  با قرارداد جداگانه.
- وابستگی‌های واقعی پس از بررسی مخازن ثبت می‌شوند.

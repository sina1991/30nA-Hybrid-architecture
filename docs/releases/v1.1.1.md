# v1.1.1 — ۲۰۲۶-۱۱-۰۱

این نسخه صفحهٔ Login و Music Player را به امکانات Dashboard، Media و معاملهٔ دمو اضافه می‌کند. مهاجرت دادهٔ مخرب ندارد و state خارج از checkout حفظ می‌شود.

## قابلیت‌ها

- Login ساده و وسط‌چین با دو تصویر اصلی تولیدشده با AI: آسمان شب و سطح سیارهٔ بدون جو. انتخاب اولیه تصادفی، تعویض ۳۵ثانیه‌ای هنگام نمایش Login، و رعایت reduced motion.
- نمایش IP همان کاربر پیش از Login با تکیه بر request و Proxy معتبر، بدون سرویس خارجی.
- Username/Password با نام فیلد و autocomplete استاندارد، Show/Hide و Credential Management اختیاری. ذخیرهٔ رمز تابع انتخاب کاربر/مرورگر است؛ Password و Session Token در localStorage پروژه ذخیره نمی‌شوند.
- اسلات Note مینیمال با متن ساده، ویرایش از Settings → Module، ذخیرهٔ owner-scoped و سازگاری CLI/Save/Load.
- Music Player مستقل در CLI/Backend/Slot و Media: Playlist شخصی تا ۱۰ Track از لینک صوتی HTTPS یا فایل مجاز، کنترل مشترک و پخش پیوسته بین تب‌ها. خروج از حساب، Save مجدد فهرست یا Reload پخش را متوقف می‌کند.
- امکانات جمع‌شده از v1.1.0: Indicators زمانی و سطوح روی Chart، Settings تب‌بندی‌شده و Output مستقل، قالب‌های مشترک Save/Load، My IP، اسلات خطی Economic Calendar، Demo Trading و گزارش‌ها، Media/YouTube و Upload/URL download.
- رفع محدودیت عمومی Nginx قدیمی ۱ MiB در Installer و Updater؛ آپلود binary و دریافت از URL تا ۲۰ MiB با حفظ Public/Direct. دانلود URL با pin کردن IP عمومی، TLS hostname verification، کنترل redirect/حجم/زمان و منع آدرس‌های داخلی.

## به‌روزرسانی سرور

روی VPS نصب‌شده با Installer، پس از Backup سازگار از state و تنظیمات:

```bash
sudo bash -c 'bash <(curl -fsSL https://raw.githubusercontent.com/sina1991/30nA-Hybrid-architecture/v1.1.1/scripts/deployment/update_dashboard.sh) v1.1.1'
```

پس از پایان، صفحه را Reload، با حساب خود وارد و Login/Playlist/Upload/Demo را بررسی کنید. نصب جدید نیز از install.sh همین Tag استفاده کند. state پیش‌فرض `/var/lib/30na/dashboard` است؛ آن را حذف نکنید. برای Rollback کد از updater با Tag/Commit قبلی استفاده کنید؛ Rollback نسخه‌های فاقد schema/owner جدید نیازمند برنامهٔ سازگار Backup/Restore است.

## اعتبارسنجی و حدود واقعی

در بررسی محلی، ۱۳۴ تست قابلیت‌های Dashboard/API/CLI/owner isolation و Chromium موفق شدند. مجموعهٔ Unit پروژه نیز ۳۰۸ تست و ۶۵ subtest موفق داشت؛ ۱۱ مورد مربوط به Docker/Browser در حالت unit-only کنار گذاشته شدند و تست Browser جداگانه اجرا شد. انتشار خودکار به موفقیت CI روی SHA همان main وابسته است. نتیجهٔ CI همان Commit را در GitHub Actions بررسی کنید. نصب واقعی، شبکهٔ منبع خارجی، رفتار همهٔ Password Managerها و Playback همهٔ Codecها روی VPS مشتری تأیید نشده‌اند.

Demo فعلاً paper trading USD/XAUUSD با قیمت نمونه‌برداری‌شده و Spread شبیه‌سازی‌شده است؛ بروکر MT5 یا پول واقعی ندارد و با قیمت stale معامله نمی‌سازد. Worker ارسالی کاربر فقط در Sandbox اجرا می‌شود. YouTube تابع دسترسی مرورگر و اجازهٔ Embed است؛ Login Google محدودیت‌های پخش را دور نمی‌زند. پخش ممتد موسیقی در همان صفحه/مرورگر است، نه پس از بستن یا Reload صفحه. Session در حافظه است و Reload ممکن است Login دوباره با Autofill بخواهد. محدودیت ۲۰ MiB برای Upload/Import و ۳۲ MiB برای فایل پوشهٔ رسانهٔ سرور برقرار است.

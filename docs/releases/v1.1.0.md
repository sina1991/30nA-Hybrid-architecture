# v1.1.0 — ۲۰۲۶-۱۰-۳۰

این انتشار قابلیت حساب‌های چندکاربره و Chat را اضافه می‌کند. بخش‌های قدیمی پروژه در این سند بازنویسی نشده‌اند.

## قابلیت‌های تازه

- ورود با Username/Password، نقش Admin/User، ساخت و فعال/غیرفعال‌کردن حساب و ابطال Session.
- Workspace مستقل و Credentialهای جداگانه Manager/Runtime/CODE برای هر owner.
- Chat Box عمومی و خصوصی با درخواست و پذیرش، انتخاب اتاق در Slot و دسترسی از CLI.
- نصب timer همگام‌سازی حساب‌ها توسط Installer و Updater؛ حفظ حساب و داده‌های `customer`.

## ارتقا

پس از تهیه Backup سازگار از state و تنظیمات Installer، روی VPS نصب‌شده با root اجرا کنید:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/sina1991/30nA-Hybrid-architecture/v1.1.0/scripts/deployment/update_dashboard.sh) v1.1.0
```

با Token موجود وارد شوید و در **Account & Settings → User administration**، Username و Password جدید Admin را تعیین و **Initialize administrator** را انتخاب کنید. این Password مخصوص Dashboard است. سپس حساب‌های دیگر را بسازید؛ آماده‌شدن دسترسی Worker منتظر sync می‌ماند.

## اعتبارسنجی و محدودیت‌ها

مجموعه Unit: 308 passed، 11 skipped و 65 subtests passed. مجموعه هدفمند API و Chromium: 76 passed؛ این دو مجموعه همپوشانی دارند. بررسی syntax Python/JavaScript/Shell، فایل‌های systemd و freshness مستندات انجام شده است. آزمون Docker، نصب واقعی VPS و restore عملیاتی اجرا نشده‌اند؛ انتشار به‌معنای پذیرش Production نیست.

پیام‌های Chat روی سرور ذخیره می‌شوند و E2EE ندارند. Session تا ۱۲ ساعت معتبر است. ابطال Session فوری و لغو Credential داخلی در نوبت بعدی timer است؛ اجرای Worker در حال انجام ممکن است ادامه یابد. Rate limit ورود محلی و حافظه‌ای است. بازگشت به نسخه قدیمی نیازمند هماهنگی timer و Credentialها طبق راهنمای ارتقا است.

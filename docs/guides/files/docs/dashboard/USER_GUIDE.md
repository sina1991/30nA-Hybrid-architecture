# راهنمای کاربر Dashboard — v1.1.1

## ورود و حساب

آدرس Dashboard یا `/login` را باز کنید. Username و Password را وارد و `Sign in` را انتخاب کنید. `Show/Hide` رمز را آشکار یا مخفی می‌کند. ذخیرهٔ رمز و Autofill به تنظیمات Password Manager مرورگر بستگی دارد؛ پروژه رمز را در localStorage ذخیره نمی‌کند. Session فعلی در حافظهٔ صفحه است؛ با Reload ممکن است دوباره ورود لازم باشد، ولی مرورگر می‌تواند فیلدها را پر کند. برای راه‌اندازی اولیه با Token، `Use an access token` را باز کنید. حساب‌های دیگر در `Account & Settings` توسط Admin ساخته می‌شوند. `Sign out` پخش موسیقی و داده‌های نمایشی حساب را پاک می‌کند؛ Worker پذیرفته‌شده الزاماً متوقف نمی‌شود.

IP مشاهده‌شدهٔ همان درخواست زیر فرم Login نمایش داده می‌شود؛ پشت Proxy سفارشی ممکن است IP پراکسی دیده شود.

Login دو تصویر تولیدشده با AI دارد: آسمان شب و منظرهٔ سیارهٔ بدون جو. تصویر نخست تصادفی است و هنگام نمایش صفحهٔ ورود هر ۳۵ ثانیه عوض می‌شود؛ با `prefers-reduced-motion` تعویض زمان‌دار متوقف است.

## Overview و Slots

در `Modules` ماژول را پیدا و به Overview اضافه کنید. در `Slots` نیز اسلات جدید بسازید و Module را انتخاب کنید. تنظیمات اسلات عادی با راست‌کلیک باز می‌شود: `Slot actions`، `Input`، `Commands`، `Slot Worker`، `Output` و `Module`. `Commands` دستور Terminal واقعی را نشان می‌دهد. Pin/Lock/Minimize و Duplicate از تنظیمات قابل دسترسی‌اند. اسلات ویژهٔ Chart از کنترل‌های خود استفاده می‌کند؛ انتخاب Indicators از آیکون روی Chart نیز ممکن است.

`Edit layout` برای جابه‌جایی و اندازهٔ اسلات‌هاست. `Save` قالبی با نام دلخواه برای کاربران واردشده ذخیره می‌کند؛ `Load` برای کاربر گیرنده کپی‌های مستقل می‌سازد. حساب دمو، معاملات، Playlist خصوصی، Credential و متن Chat خصوصی منتقل نمی‌شوند. خلاصهٔ Output، فونت و رنگ‌ها ظاهر را تغییر می‌دهند، نه پاسخ واقعی API یا Terminal.

## Note

در Slots دکمهٔ `+ Note` یک اسلات یادداشت می‌سازد. برای نوشتن یا ویرایش، راست‌کلیک → Module → Note text → Save note. خود اسلات فقط متن ساده و چندخطی را نشان می‌دهد؛ HTML اجرا نمی‌شود. متن حداکثر ۱۰هزار کاراکتر، برای همان owner و Slot روی سرور ذخیره می‌شود و از CLI ماژول slot-note نیز در دسترس است. Pin آن را به Overview می‌آورد و Save/Load مشترک متن را به‌صورت کپی مستقل منتقل می‌کند.

## Upload Center و Media

در Upload Center فایل تا ۲۰ MiB را انتخاب کنید. `Public` یعنی قابل دانلود برای کاربران واردشده؛ `Direct` فقط برای فرستنده و گیرندهٔ انتخاب‌شده است. `Copy download link` احراز هویت را حذف نمی‌کند. فقط فرستنده فایل را حذف می‌کند. نام فایل، حجم، فرستنده/گیرنده و زمان در فهرست دیده می‌شوند.

`Download from URL` فایل مستقیم عمومی HTTPS را روی سرور ذخیره می‌کند؛ نام اختیاری است و همان انتخاب Public/Direct اعمال می‌شود. لینک صفحهٔ YouTube فایل MP4 نیست. دانلود ناقص، بزرگ‌تر از حد یا از آدرس داخلی ذخیره نمی‌شود. فایل‌های سرور و Upload هرگز خودکار اجرا نمی‌شوند.

در Media نوع Image/Audio/Video یا Auto را انتخاب کنید. منبع External لینک مستقیم HTTPS یا ویدئوی YouTube است؛ منابع دیگر Upload Center و پوشهٔ مشترک سرورند. با `Load media` بارگیری و با `Unload` آزاد کنید. `Add to Overview` یک اسلات مستقل می‌سازد. فرمت‌های معمول JPG/PNG/GIF/WebP، MP3/WAV/OGG/M4A و MP4/WebM پشتیبانی می‌شوند؛ Codec و اجازهٔ Embed به مرورگر/ارائه‌دهنده وابسته‌اند. پوشهٔ سرور پیش‌فرض `/var/lib/30na/dashboard/media` و سقف فایل آن ۳۲ MiB است. این پوشه برای کاربران پروژه مشترک است؛ فایل خصوصی را در Upload Center به حالت Direct بارگذاری کنید.

## Music Player

در Media بخش Music Player را باز کنید. `Add track` را بزنید، عنوان بدهید و لینک مستقیم صوت یا فایل صوتی موجود در Upload/Server را انتخاب کنید. حداکثر ۱۰ Track دارید. `Save playlist` فهرست شخصی همان حساب را ذخیره می‌کند. برای فایل تازه، `Refresh audio sources` را بزنید؛ پخش فعلی قطع نمی‌شود.

با Play پخش شروع می‌شود؛ Previous/Next و فهرست Trackها آهنگ را تغییر می‌دهند. کنترل صدا و Seek در پلیر پایین صفحه است. `Add Music Player to Overview` کنترل همان پخش را در اسلات اضافه می‌کند؛ چند اسلات پخش‌های موازی ایجاد نمی‌کنند. تغییر تب، بازسازی اسلات و بستن تنظیمات موسیقی را قطع نمی‌کنند. Stop music، خروج از حساب، بستن/Reload صفحه پخش را متوقف می‌کنند. Save دوبارهٔ Playlist نیز پخش فعلی را متوقف می‌کند. پس از ورود پخش خودکار نداریم. Playlist روی سرور است، اما پخش و مصرف Codec در مرورگر انجام می‌شود؛ فایل محلی سرور ترافیک مصرف می‌کند.

## دکمهٔ مرورگر مستقل

دکمهٔ کوچک و بدون متن زیر IP در Login، سرویس اختیاری مستقل را در صفحهٔ جدید روی پورت 9443 باز می‌کند. این دکمه به Login داشبورد نیازی ندارد. حساب‌ها و Password آن مستقل‌اند؛ نصب جداگانه و منابع کافی لازم است. با بستن صفحه، Session موقت مرورگر پایان می‌یابد.

# v0.1.2 — Dashboard، CLI و پایش سرور

این نسخه شامل جست‌وجوی Module در Slotها، CLI تعاملی انگلیسی با Status، مسیر منو و رنگ، اجرای مستقل Module و نتیجه مشترک Slot در Dashboard و ترمینال است. هشت Module محلی برای System، Service، Disk، Network، Process، Log، Docker و Alerts ارائه می‌شوند؛ [فرمان‌ها و تنظیمات دسترسی](../development/modules-terminal.md).

Log Viewer و Docker Monitor به تنظیم و مجوز مدیر سرور نیاز دارند. Alerts هنگام اجرای Module ارزیابی می‌شود و notification یا scheduler نیست. دسترسی به host monitor از Dashboard به ownerهای تنظیم‌شده محدود است. Moduleهای Website/API، SSL، API Data، Price، Weather و اتصال BiQuote/XAUUSD در این نسخه پیاده‌سازی نشده‌اند.

تأیید ظاهر Dashboard توسط کاربر با پذیرش نهایی Production برابر نیست. امنیت Rootless روی VPS، fault injection و تمرین restore به بررسی مستقل نیاز دارند. CI و بررسی اسناد روی commit انتشار الزامی است.

برای نصب روی Ubuntu 24.04 خالی:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/sina1991/30nA-Hybrid-architecture/v0.1.2/install.sh) --ref v0.1.2
```

برای به‌روزرسانی Dashboard نصب‌شده:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/sina1991/30nA-Hybrid-architecture/v0.1.2/scripts/deployment/update_dashboard.sh) v0.1.2
```

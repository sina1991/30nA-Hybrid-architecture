# v0.1.0 — پنل مدیریت Worker و اجراها

نسخه MVP برای Workerهای trusted و Artifactهای منتشرشده؛ `main` مرجع اصلی نصب و توسعه است.

- مدیریت Worker: ثبت، جزئیات immutable، ویرایش configuration و schedule، enable/disable و حذف با تأیید شناسه.
- اجرای JSON، نتیجه و polling، history و فیلتر وضعیت/شناسه روی ۱۰۰ اجرای اخیر؛ حفظ history پس از حذف Worker.
- owner isolation، token فقط در حافظه browser، تأیید صریح عملیات و جلوگیری از اعمال پاسخ session قدیمی.
- نصب Ubuntu 24.04 با Rootless Docker، HTTPS و Certbot standalone؛ updater مستقل Dashboard با rollback startup.
- دفترچه فارسی، PDF، راهنمای مستقل Agent، OpenAPI و source inventory همراه این Release هستند. `SHA256SUMS` فایل‌های پیوست را پوشش می‌دهد؛ source archiveهای خودکار GitHub جدا هستند.

اعتبارسنجی پیش از انتقال: `315 passed, 65 subtests passed` در هر دو Python 3.11/3.12، شامل Chromium و اتصال واقعی HTTPS/Docker. CI دقیق commit انتشار نیز باید موفق باشد. log operator موفقیت نصب و اجرای نمونه نسخه قبل روی VPS را گزارش می‌کند؛ این انتشار خودکار VPS را تغییر نمی‌دهد.

این نسخه تأیید امنیت اجرای کد ناشناس یا پذیرش نهایی Production نیست. Rootless host security acceptance، daemon fault injection و restore rehearsal هنوز مستقل‌اند. RBAC/OIDC، source upload/Build در UI و pagination کامل history در scope این نسخه نیستند.

برای نصب ثابت همین نسخه روی Ubuntu خالی:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/sina1991/30nA-Hybrid-architecture/v0.1.0/install.sh) --ref v0.1.0
```

برای Dashboard نصب‌شده با installer، بدون اجرای دوباره نصب کامل:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/sina1991/30nA-Hybrid-architecture/v0.1.0/scripts/deployment/update_dashboard.sh) v0.1.0
```

پس از update، صفحه را reload و با token موجود دوباره وارد شوید. updater فقط Dashboard را restart می‌کند؛ backend و state تغییر نمی‌کنند. خود updater هنوز روی VPS واقعی آزمایش نشده است؛ سناریوی پذیرش راهنمای update را پس از اجرا بررسی کنید.

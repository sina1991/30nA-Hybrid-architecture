# DATA Contracts

مرجع رفتار فعلی و اختلاف قراردادهای قدیمی: [دفترچه جامع](../../docs/manual/04-data-manager.md) و [دفتر اختلاف‌ها](../../docs/manual/19-troubleshooting-and-gaps.md). وجود label قرارداد به معنی پذیرش deployment نیست.


این قراردادها متعلق به DATA MANAGER هستند و وضعیت آن‌ها تا بازبینی نهایی `draft` است.
قراردادهای مشترک CORE فقط مصرف می‌شوند و این پوشه معنای آن‌ها را بازتعریف نمی‌کند.

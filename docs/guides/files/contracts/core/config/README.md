# Shared Configuration

این بخش فقط تنظیمات واقعاً مشترک را تعریف می‌کند.

تنظیمات اختصاصی یک سرویس یا Agent نباید به CORE منتقل شود.

هر configuration مشترک باید:

- نام و معنای مشخص داشته باشد
- default مشخص یا صراحتاً بدون default باشد
- نوع مشخص داشته باشد
- رفتار در صورت نبودن مقدار مشخص باشد
- امکان اضافه‌شدن configuration جدید بدون شکستن مصرف‌کنندگان را داشته باشد

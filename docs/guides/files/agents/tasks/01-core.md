# Agent 01 — CORE

## وضعیت
مرحله 1: بررسی و طراحی؛ فقط خواندنی.
هیچ کدی را تغییر نده.

## مالکیت
- contracts/core/
- استانداردها و قراردادهای مشترک پروژه

## مخازن قابل بررسی
- /tmp/30na-inventory/db-gold
- /tmp/30na-inventory/unit2
- /tmp/30na-inventory/dashboard-core

این مسیرها نسخه‌های بررسی‌شده مخازن هستند. آن‌ها را تغییر نده.

## مأموریت
1. ابتدا مراحل کار خودت را اعلام کن.
2. قراردادها، مدل‌ها، شناسه‌ها، وضعیت‌ها، خطاها،
   تنظیمات و استانداردهای مشترک موجود را در هر سه مخزن شناسایی کن.
3. قابلیت‌های تکراری، ناسازگار، آماده و مفقود را ثبت کن.
4. حداقل قرارداد مشترک موردنیاز برای ارتباط Data Manager،
   Code Manager، Worker Manager، Worker Runtime و Dashboard
   را پیشنهاد بده.
5. مواردی را که هنوز به تصمیم معماری نیاز دارند جداگانه فهرست کن.
6. وابستگی‌های ضروری را مشخص کن؛ منطق اختصاصی سایر واحدها را
   به CORE منتقل نکن.
7. گزارش نهایی را به فارسی ارائه کن.

## خروجی مورد انتظار
- فهرست قراردادهای مشترک موجود با مسیر فایل
- فهرست قراردادهای تکراری یا متعارض
- پیشنهاد ساختار contracts/core/
- پیشنهاد شناسه‌ها، وضعیت‌ها، خطاها و نسخه‌بندی قراردادها
- وابستگی‌ها و تصمیم‌های باز
- برنامه پیشنهادی مرحله پیاده‌سازی

## ممنوعیت‌ها
- هیچ فایلی را ایجاد، حذف یا ویرایش نکن.
- هیچ مخزنی را ادغام یا منتقل نکن.
- قراردادهای نهایی را بدون تأیید تثبیت نکن.
- در پایان منتظر تأیید برای مرحله پیاده‌سازی بمان.
